KEY FEATURES IMPLEMENTED
================================================================================

RTL SUPPORT
-----------
- Automatic RTL/LTR detection based on language (ar, ur = RTL)
- Sidebar positions dynamically (right for RTL, left for LTR)
- Uses logical properties (ms-*, me-*) instead of (ml-*, mr-*)
- Cairo font optimized for Arabic text

DARK/LIGHT MODE
---------------
- Toggle button in header
- Persistent state via localStorage
- Default: Dark mode
- All components support both modes
- Smooth transitions between modes

GLASSMORPHISM DESIGN
--------------------
- Backdrop blur effects on header and sidebar
- Glass utility classes (.glass, .glass-dark, .glass-light)
- Translucent backgrounds with border highlights
- Premium Netflix-inspired aesthetic

COLOR SCHEME
------------
Primary Gradient: #0056b3 (blue) → #218838 (green)
Accent Color: #64CCC5 (teal)
Usage:
  - Primary buttons: bg-gradient-primary
  - Hover states: text-accent
  - Active menu items: bg-gradient-primary text-white
  - Shadows: shadow-glow (teal glow effect)

ANIMATIONS
----------
Available keyframes:
  - fadeInUp: 0.6s ease-out (fade + upward movement)
  - fadeIn: 0.8s ease-out (simple fade)
  - slideInRight: 0.5s ease-out (horizontal slide)
  - shimmer: 2s infinite (loading effect)

Stagger delays: Add style="animation-delay: 0.1s" for sequential loading

SIDEBAR NAVIGATION
------------------
Menu Structure:
  - Dashboard
  - Content (expandable)
    - Articles
    - Categories
    - Tags
  - Media (expandable)
    - Programs
    - Episodes
  - Hadith
  - Quran
  - Genealogy
  - Users
  - Roles
  - Analytics
  - Settings

Features:
  - Active state highlighting with gradient background
  - Hover effects with smooth transitions
  - Collapsible submenus with Alpine.js
  - Icons for all menu items (Lucide)
  - User profile section in footer
  - Storage usage indicator

HEADER COMPONENTS
-----------------
1. Hamburger Menu Button
   - Toggles sidebar on mobile
   - Scales on hover

2. Breadcrumbs
   - Pass $breadcrumbs array from controller
   - Auto-generated if not provided
   - Format: [['label' => 'Name', 'url' => '/path'], ...]

3. Search Bar
   - Desktop: Full search input with dropdown
   - Mobile: Icon button only
   - Quick results dropdown
   - Clear button when typing

4. Language Switcher
   - Dropdown with 5 languages (ar, en, tr, fr, ur)
   - Active language highlighted with gradient
   - Flag emoji or language name display

5. Dark/Light Toggle
   - Sun icon for dark mode
   - Moon icon for light mode
   - Persists to localStorage

6. Notifications
   - Bell icon with red badge
   - Dropdown with notification list
   - Categorized by type (user, article, video, etc.)
   - View all link at bottom

7. User Profile Menu
   - Avatar with initials
   - User name and email
   - Dropdown with Profile, Settings, Help
   - Logout button (red color)

RESPONSIVE BEHAVIOR
-------------------
Mobile (< 1024px):
  - Sidebar hidden by default
  - Hamburger menu shows sidebar as overlay
  - Click outside to close
  - Search icon instead of full search bar

Desktop (>= 1024px):
  - Sidebar always visible
  - Full search bar shown
  - User info visible in profile menu

ALPINE.JS STATE MANAGEMENT
---------------------------
Global state variables:
  - darkMode: Boolean (from localStorage)
  - sidebarOpen: Boolean (window.innerWidth >= 1024)
  - currentLang: String (app locale)

Methods:
  - toggleDarkMode(): Switch theme + save to localStorage
  - toggleSidebar(): Show/hide sidebar
  - changeLang(lang): Switch language + reload page
