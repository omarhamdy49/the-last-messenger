## Key Features by File

### master.blade.php (Master Layout)
- HTML5 doctype with RTL support
- Theme mode management (light/dark)
- Asset loading (CSS, JS, fonts)
- Blade sections (@yield, @stack)
- CSRF token meta tag

### sidebar.blade.php (Navigation)
- Collapsible sidebar
- Hierarchical menu with accordion
- Active state highlighting
- Keenicons for menu items
- Scrollable content area
- Logo display (default + mini)

### header.blade.php (Top Bar)
- Mobile responsive
- Search button
- Notifications dropdown
- Theme toggle
- Language switcher
- User menu with avatar

### footer.blade.php (Footer)
- Copyright notice
- Navigation links
- Responsive layout

### dashboard/index.blade.php (Dashboard)
- 4 Statistics cards (gradient backgrounds)
- 2 Charts (area + donut)
- Recent activity table
- Quick actions grid
- Welcome card with CTAs

## Maintenance Notes

CSS Updates:
- All styles in styles.css (don't edit directly)
- Use Tailwind classes in templates
- Custom styles go in @stack('styles')

JavaScript Updates:
- Core functionality in core.bundle.js
- Layout scripts in layouts/demo1.js
- Custom scripts go in @push('scripts')

Asset Management:
- Don't delete files from public/admin/vendors/
- Keep icon fonts in vendors/keenicons/fonts/
- Compress images before adding to media/

Template Conventions:
- Use {{ __('Text') }} for all user-facing text
- Follow existing naming patterns
- Keep components modular and reusable
- Test in both light and dark modes
- Verify RTL layout for Arabic/Urdu
