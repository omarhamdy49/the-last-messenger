Instructions

  • Icon Picker: Click "Choose Icon" to browse and select from 100+ icons with category filtering
  • Color Picker: Click "Choose Color" to pick from presets or enter custom HEX color
  • Tag Autocomplete: Type to search existing tags or create new ones. Use arrow keys and Enter for keyboard navigation
  • Category Tree: Drag categories to reorder or nest them (max 5 levels deep). Click chevron to expand/collapse
