================================================================================
USAGE EXAMPLE
================================================================================

Basic Upload:
-------------
$service = new ImageUploadService();
$result = $service->uploadArticleImage($request->file('image'));

echo $result->getThumbnailUrl();  // 150x150
echo $result->getMediumUrl();     // 400x300
echo $result->getLargeUrl();      // 1200x800
echo $result->getOriginalUrl();   // Original

Update with Delete Old:
-----------------------
$result = $service->uploadArticleImage(
    file: $request->file('image'),
    oldImagePath: $article->featured_image
);

Delete Image:
-------------
$service->deleteImage($article->featured_image);

================================================================================
ERROR HANDLING
================================================================================

Exceptions:
- ImageValidationException (422) - User errors, safe to show
- ImageCompressionException (500) - Server errors, log and hide details
- ImageStorageException (500) - Server errors, log and alert admin

All exceptions extend ImageUploadException for easy catching.
