### Hard rules

1. **Never run** `migrate:fresh`, `migrate:refresh`, `migrate:rollback --step`, `db:wipe`, or any artisan command with `--database=`. The connection named `mysql` is the DEV database. Tests get their own DB from `phpunit.xml`; the only way you exercise migrations is `php artisan test`.
2. **Do not create new migration files** except the two renames in T004 and T005 (rename = `git mv`).
3. Translations: write with `$model->syncTranslations([...])`. Never `setTranslation()` + `save()`. Never add Spatie `HasTranslations`. Never `select('name')` on a parent table for a translated field.
4. `order` is a MySQL reserved word. It is fine in `->orderBy('order')`, `->select([...,'order'])`, `$table->integer('order')`. In any `selectRaw` / `orderByRaw` / `DB::statement` write it as `` `order` ``.
5. Files under `app/Domain/Seerah/` may import only from `App\Domain\Seerah\…`, `App\Domain\Shared\…`, `App\Exceptions\…`, `App\Support\…` and framework/vendor classes. **Never `use App\Models\…`** there. `composer deptrac` enforces it. Never add entries to `deptrac.baseline.yaml`.
6. Every list query has an explicit `->select([...])` that includes the primary key and every FK used by an eager load. Eager loads name columns: `with('type:id,slug,metadata,locale')`.
7. Controllers: validate (FormRequest) → call **one** service method → return view/Resource. No Eloquent, no `DB::`, no file handling in controllers. `DB::transaction()` lives in the repository.
8. User-visible text: `__('seerah.key')`, key present in **all five** files `resources/lang/{ar,en,fr,tr,ur}/seerah.php`. Arabic is the default and fallback. When you delete a key, delete it in all five.
9. Blade layout uses logical Tailwind classes only (`ms-`, `me-`, `ps-`, `pe-`, `start-`, `end-`). No `ml-`, `mr-`, `pl-`, `pr-`, `left-`, `right-`.
10. No `catch` that swallows an error into an empty/zero fallback without `report($e)`. No `Cache::flush()`.
11. Dead code is deleted, not commented out. Tests whose subject was removed are deleted, not skipped.
12. After changing any Blade/CSS/JS file run `npm run build` before judging the page in a browser.
13. Do not touch files outside the task's list. The working tree has unrelated uncommitted changes in `resources/css/admin*.css`, `resources/js/admin/rich-text.js`, `resources/views/admin/articles/_form-wizard.blade.php`, `resources/views/admin/media-programs/_form.blade.php`, `resources/views/components/admin/{form/wysiwyg,list-card,module-selector-modal}.blade.php`, `resources/views/public/media/program.blade.php` — leave them as they are and never `git checkout`/`git stash`/`git clean` them.
