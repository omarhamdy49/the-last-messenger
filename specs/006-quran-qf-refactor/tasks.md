## READ THIS FIRST — rules for whoever implements these tasks

1. Do one task at a time, in ID order unless marked [P]. Before editing a file, **read the whole file**. After each task run its **Done when** check. If a check fails twice, stop and report — do not improvise.
2. Every PHP file starts with `<?php` + `declare(strict_types=1);`. Classes are `final` unless they are Eloquent models or abstract. Enums are backed `string` enums.
3. **Copy the house patterns, do not invent new ones**:
   - Localized model: `app/Domain/Seerah/Models/SeerahMilestone.php` (+ `SeerahMilestoneTranslation.php`) — `HasLocalizedContent`, `getTranslationModelClass()`, `getTranslatableFields()`.
   - Importer client + mappers + report: `app/Domain/Hadith/Import/Sunnah/` (`SunnahApiClient`, `*Data` DTOs, `*ImportService`, `*WriteResult`).
   - Admin controller / FormRequest / views: `app/Http/Controllers/Admin/Seerah/SeerahMilestoneController.php`, `app/Http/Requests/Admin/StoreSeerahMilestoneRequest.php`, `resources/views/admin/seerah-milestones/`.
   - Repository with versioned cache: `app/Domain/Shared/Repositories/BaseRepository.php` + `app/Domain/Quran/Services/QuranCacheKeys.php` (keep this file, rename scopes in T041).
   - API resource + test: `app/Http/Resources/SeerahEventResource.php`, `tests/Feature/Api/QuranApiTest.php` (setUp with `Sanctum::actingAs`), `tests/Feature/NoNPlusOneQueriesTest.php`.
   - Queued command runner: `app/Jobs/RunArtisanCommandJob.php`, registry `config/artisan-commands.php`.
   - Cross-module contract: `app/Domain/Shared/Contracts/MediaLibraryLookup.php` + its impl under `app/Services/`.
4. **Translations live in `*_translations` tables**, written with `syncTranslations([...])`, read with `getTranslation('name', $locale)`. Never `setTranslation()`, never JSON columns for names.
5. **Never** `migrate:fresh`, `--step`, `--database=`, `Cache::flush()` in app code, `Model::all()`, bare `->get()` without `select`, `$guarded = []`, empty `catch`.
6. Every new user-facing string is a key added to **all five** files `resources/lang/{ar,en,fr,tr,ur}/quran.php` (Arabic first). Layout uses logical Tailwind classes (`ms-`, `me-`, `ps-`, `pe-`, `start-`, `end-`).
7. Tests run on MySQL: `php artisan test --filter=<Class>`. Run `./vendor/bin/pint` on every file you touch. Run `composer deptrac` after touching anything under `app/Domain`.
8. Migrations: FULLTEXT and raw `ALTER` inside `if (DB::getDriverName() === 'mysql')`. Every `down()` drops what `up()` created, in reverse order.
9. The QF secret and API-client secrets **never** appear in logs, exceptions, or test output.
10. `[P]` tasks may be handed to parallel workers only if they list different files.
